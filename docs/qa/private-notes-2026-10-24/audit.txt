Private Notes implementation and browser audit — 24 October 2026

Implemented:
- /pms/notes and /pms/projects/:projectId/notes.
- Owner-only notes independent of project/workspace membership.
- Markdown editor/preview, autosave, manual save, search in title/body, tags,
  pinning, archive, soft-delete/restore, immutable revisions and Markdown export.
- Optional project/task links, validated against current project access.
- Sidebar, workspace navigation, Quick Add and project dashboard entry points.
- Version checks prevent stale tabs overwriting newer saves.
- Failed saves retain the in-memory draft; links and browser unload warn before loss.

Privacy audit:
- Every read/write/history/restore operation scopes the note to current_user.id.
- Another administrator cannot access a user's notes through the notes API.
- Client-supplied owner_id is rejected.
- Linking a project/task never grants collaborators note access.
- Revoked/deleted project context does not expose project/task names.
- Private notes and revisions are explicitly excluded from workspace savepoint exports.
- No note content is emitted to project activity, notifications, or AI tools.
- Existing Markdown renderer escapes content and restricts links to HTTP(S).
