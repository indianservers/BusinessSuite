Company Assets lifecycle implementation and QA - 10 November 2026

Implemented
- Existing assets and asset_assignments remain the source of truth. No second register, custody table, exit case table, notification queue, approval table or attachment table was introduced.
- Atomic multi-asset handovers, tenant-scoped request-key reservation, deterministic row locking, unique active custody index, expected return dates, accessories and separate handover evidence.
- Employee-only acknowledgment, retained transfer history, custody extensions, return requests and downloadable group handover receipts.
- Physical returns are held as Pending Inspection. Inspector findings and before/after evidence are preserved. Approval OS decisions apply the domain transition in the same transaction.
- Recoveries require enabled company policy, a policy reference and an independent authorized decision. Approved settlements retain a reference. No automatic employee charge or payroll deduction is created.
- Approved exceptions for recorded loss, damage or missing accessories; configurable damage and missing-item clearance rules.
- Employee reminders link to the existing Self Service asset panel. Shared asset evidence uploads additionally require asset_manage; unrelated HR edit permission is insufficient.
- Existing exit cases and department checklists are reused. Pending return, inspection, recovery and required exceptions block asset clearance. Asset sign-off completes only asset checklist tasks; company-wide exit remains independent.
- Private evidence and invoice uploads use the shared ServiceDocument adapter and authorized download API. Type signatures, quotas, version history and record access are enforced by that service.
- Configurable reminder lead time, repeat interval, recipients and channels. Existing email worker/authenticated cron processes enabled policies. Delivery uses existing NotificationService and WhatsApp workspace controls. Tenant/branch checks and durable event keys prevent duplicate or unauthorized alerts.
- PDF handover receipts and asset-only clearance certificates; CSV and Excel exports; paged custody/return registers, search, date filters, department filters, sorting and grouping; employee asset profiles and Asset 360 history.
- Application sidebar, navigation, workspace switcher and global shell were not redesigned.
