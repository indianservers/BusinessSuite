ARCHITECTURE / POLICY
Four additive tables: pms_chat_conversations, pms_chat_members, pms_chat_messages, pms_chat_attachments. Existing source tables remain authoritative for legacy identifiers. A repeat-safe, bounded, locked lazy adapter copies source history without backfill notifications; current legacy DM sends use the new send path. New shared-inbox IDs have explicit legacy source-ID fields.
Workspace membership and organization context (when present) are rechecked server-side. Public means current workspace only. Guests cannot create, send, upload or manage. Private rooms require current conversation membership. Channel management: creator and joined workspace Owners/Admins. Group management: owner; leaving transfers ownership to an eligible remaining member. No one-to-one expansion into groups.
New private/group members cannot see pre-join roots or any continuations of those threads. Read/unread/search/notifications/files use this same boundary. Public self-join has public history. Every visible other-authored root or reply contributes to unread; own, deleted and edited messages do not inflate counts. Read markers never move backward.
Only content-free hints travel over realtime to current room/workspace members. Removed members receive one invalidation, then no room events. Every payload/download/search goes through current API authorization. Serverless/offline recovery uses durable APIs on a 10-second poll.
Search: 12 words/200 characters max, all terms, newest IDs first. PostgreSQL simple-dictionary FTS + GIN; SQLite escaped case-insensitive substring fallback. Dates use UTC. Deleted and inaccessible history/files are excluded before returning results.
Files: existing private local/S3/Vercel Blob abstraction, configured upload ceiling, safe UUID paths, extension/signature validation, owner-bound staging, savepoint-backed atomic message/attachment association. Project files remain linked, never copied or deleted by chat. Linked project images are download-only; only signature-validated native chat images preview. Chat download responses are authenticated proxies, not public/reusable links. Hourly cleanup expires staging at 24h and deleted-message files at 30 days (configurable). Message rows/IDs remain intact.
