KaryaFlow Forms verification — 2026-10-24

Implemented at /pms/forms:
- Dedicated responsive form studio, replacing the generic intake-tools route.
- Click-to-add fields; pointer, touch-sensor and keyboard sorting; move and delete controls.
- Thirteen field types: text, long text, email, phone, URL, number, date, dropdown, radio, multiple choice, consent checkbox, rating and section.
- Field labels, help, placeholders, required answers and numeric bounds.
- Conditional visibility based on an earlier answer; hidden values are discarded server-side.
- Draft/published snapshots, optimistic revision conflicts, published version validation, close/reopen by publishing.
- Support, project and feedback starters; definition JSON export/import; color and receipt customization.
- Workspace share links require authentication; Guests may view but cannot submit.
- Responses are private to workspace Owner/Admin, paginated and linked to created tasks.
- CSV and JSON response exports; CSV formula protection. Preview supports browser Print/Save PDF.
- Workflow project/title mapping, assignee, priority and relative due date.
- Existing project task.created automation rules run transactionally with task and response creation.
- UUID replay prevention and savepoints prevent duplicate tasks and partial workflow writes.
- Existing workspace-entry storage is reused; no new Forms database migration required.
- Legacy basic intake forms remain available in Workspace tools.
