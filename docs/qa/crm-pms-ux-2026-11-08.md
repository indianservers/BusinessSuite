# CRM and PMS usability updates — 8 November 2026

## Delivered in this batch

- Deals shows three primary metrics. Won/lost counts, inactivity and per-currency pipeline/weighted totals remain accessible under **More sales metrics**; currencies are not combined.
- Pipeline, stage and owner are always available as quick filters. Other criteria remain under **Advanced filters**, with an active count visible while collapsed. Changing pipeline clears its stage. Clear filters resets both external criteria and grid search/filter rules.
- New/default deal view bars emphasize Table, Board and Forecast. Every other view remains available through the view catalog. Existing pinned-view preferences are retained.
- CRM/PMS module navigation is a compact **Switch workspace** popover instead of a second full-width view bar. The original module pin preference keys are reused; pins sort first within their category. Escape closes the popover and returns focus to its trigger. Workspace links remain ordinary anchors.
- PMS workspace links preserve workspace/project query context. Browser Back retains the original destination/context.
- Existing project workflow and transition-approval pages are discoverable in the PMS menu and workspace switcher. Route and backend permission enforcement are unchanged.
- CRM navigation uses **Companies**, **Contacts**, **Quotes**, and **Quote builder**. Legacy URLs and separate register/builder functionality remain. Legacy company/quote screens use matching headings and labels.
- Related-operation navigation uses a compact section label rather than adding a second page-level heading.

No database schema, record identity, provider connection or production data was changed. Other work already present in the shared checkout is outside this batch.
