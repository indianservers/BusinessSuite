LIVE FIXES
1. Empty cursor-mode history returned total:null, leaving a blank section. The
   shared workspace now uses items.length to show its empty-state message.
2. A follow-up page repeated the same native task authorization for every row.
   It now checks each distinct task once per response. There is no cross-request
   authorization cache: every page/request rechecks current permissions.
   Profiling also found that native permission lookups eagerly reloaded assignees
   on already loaded tasks. The native lookup now uses lazy loading; intern
   assignment checks still load assignments when needed. This preserves native
   authorization while avoiding five redundant relationship queries on five rows.
   The instrumented local check fell from about 62 to 20 seconds; profiling adds
   overhead, so these figures are diagnostic and are not production latency claims.
3. Link controls no longer wait for the work feed to finish refreshing after a
   successful mutation. Reused the API's existing suite:record-mutated event for
   cursor reset/refresh, and invalidated work/history without blocking controls.
